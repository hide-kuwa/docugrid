# アドオン

要約: 設定の **アドオン** で、公式パックをこの事務所に付けたり外したりします。こちら側だけが操作できる専用アドオンもあります。うまくいった下書きは、運営が **公式** に昇格して他事務所も付けられるようにします。

対象: 所長・設定担当

---

## 開き方

**設定** → **アドオン**

開発コンソール（プラットフォーム権限）では、下書き作成・事務所への配布・公式昇格ができます。

---

## できること

- 公式アドオンを **付ける / 外す**
- パイロット対象なら、まだ公式でないパックも付ける

## できないこと

- こちら専用（internal）の付け外し
- 他事務所の下書きの閲覧
- コードや判定エンジンそのものの編集（定義の箱だけ）

ヘルプ: 判定ロジックは共通、条件セットがアドオンです。
