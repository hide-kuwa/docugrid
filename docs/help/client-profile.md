# 顧客詳細（プロフィール）

要約: 事務所設定の **顧客詳細** で、顧問先ごとの住所・連絡先などの文字情報を登録します。上部で **担当者** を付け替え、下の方にはめったに使わない **移管** があります。顧客名・決算月の変更は **顧客マスタ** 側です。

対象: 所長・事務所設定担当（`settings.manage`）

---

左一覧の上部で **名前・ID・かな・顧客コード** を検索して絞り込めます。  
**顧客マスタ** の顧問先カードから飛んできたときは、その顧問先が最初から選ばれます。  
スクロール中に固定されるのは右上の **顧問先名**（と横の保存）だけです。

## よく使う操作（上）

- **担当者**: チェックでスタッフを付け外し → **担当を保存**（担当マスタと同じスコープ）
- **基本情報** など各セクションの項目編集 → 右上の **保存**

## e-Tax ログイン補助

申告関係セクション内。法人／個人のログイン画面を開き、登録済みの利用者識別番号をクリップボードへコピーします。暗証番号は別ボタンでコピー。国税庁サイトへ自動入力はブラウザが禁止しているためできません。

## 移管（一番下）

画面下部の「めったに使わない操作」から移管コードを発行します。詳細は [client-transfer.md](./client-transfer.md)。

できないこと: ここから顧客の追加・削除はできません（顧客マスタ／CSV）。
