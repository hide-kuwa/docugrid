# PDF の編集

要約: 注釈・ページ並べ替え・ダウンロード／格納ができます。法人税パッケージでは左の帳票索引で別表などを自動検出し、未添付は表示中ページを手動割当できます。右の OCR 読取では修正が自動で状態保存され、顧客マスタへの反映だけ明示ボタンです。入口はレール PDF、Doc のスロット、ゲスト /pdf。ゲストはサーバー保存なし。失敗時はビューア上部のメッセージを優先。

対象: 担当スタッフ／ゲスト利用者

---

## どこから開くか

| 入口 | 保存 |
|------|------|
| レール **PDF** | ログイン後。顧問先は名前・かな検索で選べば DocuGrid へ格納可 |
| Doc のスロットからビューア | 版・監査と連動（権限による） |
| ゲスト **`/pdf`** | サーバー保存なし。ダウンロード中心 |

---

## できること（概要）

- 注釈（枠・マーカー・テキストなど）  
- **並べ替え**（ページのドラッグ、Add PDF で結合）  
- **PDF ダウンロード**（いま画面上の内容を端末へ）  
- ログイン後: **DocuGrid に格納**（顧問先の「PDF 作業」枠など）  
- Doc スロットから開いているとき: **Add PDF（結合）・並べ替え・注釈**のたびにサーバーへ **新版** が付き、過去版は履歴に残ります  
- **帳票索引**（法人税パッケージなど）: 別表・受信通知の自動検出。取りこぼしは手動割当  
- **OCR 読取**: 手動修正は自動で状態保存。顧客マスタへ載せるときだけ **マスタへ反映**  

並べ替え中の「戻る」は複数ステップ分あります。失敗時はビューア上部に理由が出ます。  
既存 PDF の上に別 PDF をかぶせた（Add PDF）あとも、最新が新 Ver になり、以前の Ver は版一覧から開けます。

---

## OCR 読取（状態保存とマスタ反映）

右の **OCR 読取** パネルでは次の 2 つが分かれています。

| 操作 | いつ残るか |
|------|------------|
| フィールドを書き換える | 自動でサーバーに状態保存（顧問先・期・枠ごと）。開き直しても残る |
| **マスタへ反映** | 押したときだけ顧客マスタへ載る（水色「手動（マスタ）」） |

黄色の「手動修正」はマスタ未反映の下書きです。資料固有の項目（事業年度など）はマスタ対象外で、状態保存のみです。

---

## 帳票索引（手動割当）

左の **帳票索引** で必須帳票・検出セクションを見ます。

- **未添付** の必須帳票をクリック → いま表示中のページをその帳票に割り当て（鉛筆アイコン）  
- 検出セクションの **追加** → 表示中ページを別表名などから選んで登録  
- 手動割当は文書を開き直すとリセット（このセッション限り）

---

## 保存の注意

- **ダウンロード**＝端末だけ  
- **格納／作業保存**＝事務所サーバー（詳細は [saving.md](./saving.md)）  
- ゲスト編集は事務所マトリクスに自動では残りません → [guest-pdf.md](./guest-pdf.md)  

---

## ゲスト利用時の注意

- ブラウザを閉じると下書きは消える（同タブでは「続ける」可）  
- ページ数やファイルサイズにサーバー側の上限があります  
- 社内 LAN から触る場合は、ホスト側で開発サーバーが起動している必要があります
