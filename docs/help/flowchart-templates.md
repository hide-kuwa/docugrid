# 判定フロー

要約: レールの **判定** で、顧問先の数字を使ったフローチャート判定と、フローそのものの作成ができます。画面のフォームで組むのでコードは不要です。保存と PDF はその時点の税法のまま変わりません。

対象: 担当スタッフ

---

## 開き方

左レールの **判定**（または `/flowchart`）。上のタブで **ひな形**（文書）と行き来できます。事務所アカウントではレールに出ません（開発者のみ）。

- **この顧問先で判定** — 選んだ顧問先のマスタ・指標でフローを実行
- **フローを作る** — ステップと「どの数字を見るか」を画面で組む

カルテの **進捗** からは、このページへの案内だけ出ます。

---

## この顧問先で判定

1. 顧問先を選ぶ（名前・かなで検索可）
2. フローを選ぶ（「消費税 課税事業者判定」または「消費税 簡易課税・事業区分」など）
3. **判定基準日** を入れる（その日の税法の版が使われます）
4. **課税事業者判定** … 条件ノードをクリックすると手動設定
5. **事業区分** … 国税庁風の図で **YES / NO** を選び、右の第1〜6種に進む
6. **この判定を保存** → **呼び出す** または **PDF**（保存時点で固定）

**最新マスタで再判定** は、いまのカルテ数字でやり直します。呼び出し中の古い判定は上書きしません。

---

## フローを作る（ノーコード）

1. **フローを作る** タブ
2. タイトル・税法の開始日〜終了日
3. **使う数字・項目** でマスタ／カルテ／指標／手入力を選ぶ
4. **判定のステップ** ではい/いいえ、または金額の条件を足す
5. 複合なら **かつ** を押す
6. **フローを登録**

公式フローを土台にするときは **これを土台に作る**。法律が変わったら **新しい期間** です。

ドラッグで線を引くキャンバスはこれから足します。いまはフォームで同じ定義を作れます。

---

## できないこと

- 税務署への届出そのもの
- ひな形に書いていない例外の自動判定
- 呼び出し中の判定をその場で再編集（いったん最新で再判定してから）
- 保存済み PDF を後の法改正に合わせて自動更新すること

---

## うまくいかないとき

| 症状 | 確認 |
|------|------|
| 数字が空 | カルテのマスタ・グラフに課税売上や資本金があるか |
| フローが増えない | **フローを作る** の権限（settings.manage） |
| この日付に当てはまる税法がない | 判定基準日がそのフローの適用期間内か |
