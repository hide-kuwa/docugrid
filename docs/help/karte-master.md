# カルテ · マスタ

要約: カルテ左の **マスタ** は、顧問先の基本情報（名称・区分・プロフィール項目など）を見る／直す画面です。資料 PDF そのものではなく、「顧客カード」に近いデータです。編集できる項目は権限によります。

対象: 担当スタッフ

---

## 開き方

1. レールで **カルテ** を開く  
2. 左の縦リスト（Doc の R8 と同じ位置）で **マスタ** を選ぶ  

---

## できること

- 顧問先名やプロフィール欄の確認  
- 権限があれば **変更 → 決定** で編集（上部に検索・入力率）  
- 関連資料がある項目は、青いチップから Doc 側へジャンプできる場合があります  

編集できない欄（ID など）は画面上でロックされています。

---

## 注意

- マスタを間違えると他画面の表示や帳票にも影響します。確定前に確認してください  
- 「正規化」「DATA 反映」などが出る操作は、資料から読み取った値をマスタへ載せる流れです（詳細は今後追記）
