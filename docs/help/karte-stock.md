# カルテ · 自社株評価（株評）

要約: カルテの **株評** は、非上場株式の評価を試算する画面です。発行済株式・純資産・利益・配当などを入力し、複数の評価方法で概算します。正規の数値とシミュレーションが分かれることがあります。税務上の最終評価は税理士確認が必要です。

対象: 担当スタッフ

---

## 開き方

**カルテ** → 左縦リストの **株評**

画面によっては工事中バナーが出ることがあります。その場合は本番確定に使わず、試算・確認にとどめてください。

---

## 最短の使い方

1. 評価の基準日・対象会社（顧問先）を確認する  
2. 基礎数値（株式数・純資産・利益・配当など）を入力または確認する  
3. 画面上の評価方法ごとの結果を比較する  
4. シミュレーション欄がある場合は「もしこの数字なら」を試し、正規値と混同しない  
5. 申告や契約に使う前に、税理士の確認と Doc 上の根拠資料を揃える  

評価方法の正式名称や適用条件は法令・通達に依存します。画面のラベルは試算の便宜上の区分です。

---

## 注意

- 試算結果をそのまま申告数値にしない  
- 入力元（決算書・株主名簿など）と食い違っていないか **Doc** の資料と照合する  
- 正規保存とシミュレーション保存が分かれているときは、正規側を上書きしない  

---

## うまくいかないとき

| 症状 | まずやること |
|------|----------------|
| 計算が空／ゼロ | 必須の基礎項目が未入力か、工事中で無効か |
| 方法が1つしか出ない | 入力条件が揃っていない／機能制限の可能性 |
| 保存できない | 権限または検証エラー。メッセージを控える |
| 以前の試算が見えない | 顧問先・基準日の切り替えを確認 |

詳細な評価理論はヘルプ対象外です。運用上の問い合わせは [support.md](./support.md) へ。
