# ワークスペース（レール）

対象: 担当スタッフ

左の **≡** を押すと（PC ではマウスを乗せる／固定でも可）、画面モードが並びます。

スマホ・タブレットでは、≡ をタップして Doc / PDF / 設定などを選びます。期間の切替は画面上部の **期間ボタン** から開きます。

| 項目 | できること | メモ |
|------|------------|------|
| **Doc** | 資料マトリクス。顧問先・期・スロット | 日々の中心 |
| **PDF** | PDF を開いて注釈・並べ替え・ダウンロード | 顧問先に紐づけて DocuGrid へ格納も可 |
| **カルテ** | 顧問先データのハブ（マスタ等） | 左縦リストで切替。→ [karte.md](./karte.md) |
| **設定** | 顧客マスタ・Drive など事務所の運用設定 | `/settings` |
| **検索** | 書類名で探す | レール下部 |
| **開発中** | DM・Tax・ひな形・判定・タスク | タップで展開 |
| **開発** | 開発コンソール | プラットフォーム管理者のみ |

---

## 初回ガイド（ツアー）との関係

初回ログイン付近では、画面が暗くなり **押すべき場所だけ明るく** なるツアーが出ることがあります（「はじめの操作」のみ自動）。  
左レールの **ヘルプ** にマウスを乗せる（スマホではタップ）と、**ガイド**（チュートリアル）と **サポート**、ヘルプセンターが出ます。  
ツアーは短い導入で、細かい手順はこのヘルプを正とします。画面へのヘルプリンクは後回しです。

---

## 操作のコツ

- レールを開いたままにしたい → ≡ を押して **固定（ピン）**（PC）
- スマホではメニュー選択後に自動で閉じます。期間は上部のボタンから
- Doc に戻ると、左は再び **永続 / R8 / R7 …** の期リストになる（「データ」行はなし）
- 顧問先のマスタ・メモなどはレールの **カルテ** のみ
- カルテに入ると、左は **メモ / マスタ / グラフ …** に切り替わる（同じ「縦ドラム」の場所）
