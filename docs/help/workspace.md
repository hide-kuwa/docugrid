# ワークスペース（レール）

対象: 担当スタッフ

左の **≡（ハンバーガー）** にマウスを乗せるか固定すると、画面モードが並びます。

| 項目 | できること | メモ |
|------|------------|------|
| **Doc** | 資料マトリクス。顧問先・期・スロット | 日々の中心 |
| **PDF** | PDF を開いて注釈・並べ替え・ダウンロード | 顧問先に紐づけて DocuGrid へ格納も可 |
| **DM** | メール／チャット統合の置き場 | 機能によっては工事中表示 |
| **Tax** | 決算・中間・源泉などの進捗ボード | |
| **カルテ** | 顧問先データのハブ（マスタ等） | 左縦リストで切替。→ [karte.md](./karte.md) |

---

## 初回ガイド（ツアー）との関係

初回ログイン付近では、画面が暗くなり **押すべき場所だけ明るく** なるツアーが出ることがあります（「はじめの操作」のみ自動）。  
左レールの **ヘルプ** にマウスを乗せると、**ガイド**（チュートリアル）と **サポート**、ヘルプセンターが出ます。  
ツアーは短い導入で、細かい手順はこのヘルプを正とします。画面へのヘルプリンクは後回しです。

---

## 操作のコツ

- レールを開いたままにしたい → ≡ を押して **固定（ピン）**
- Doc に戻ると、左は再び **永続 / R8 / R7 …** の期リストになる（「データ」行はなし）
- 顧問先のマスタ・メモなどはレールの **カルテ** のみ
- カルテに入ると、左は **メモ / マスタ / グラフ …** に切り替わる（同じ「縦ドラム」の場所）
