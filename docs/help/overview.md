# DocuGrid 概要

要約: DocuGrid は顧問先の資料 PDF を「顧問先 × 期 × 種類」で整理し、注釈・進捗・カルテまで扱うアプリです。会計仕訳の本体は別プロダクトです。ログイン後は左レールで Doc / PDF / カルテなどを切り替えます。

対象: 事務所スタッフ・所長・運用担当（はじめて触る人）

---

## DocuGrid とは

顧問先の **資料（PDF）を、顧問先 × 期 × 種類で整理** し、注釈・並べ替え・進捗・カルテまでまとめて扱うアプリです。  
会計の仕訳本体は別プロダクト（税務会計システム）側。こちらは「資料と顧客メモのハブ」です。

---

## ログイン後の全体像

```
┌ レール（左の ≡）─────────────────────┐
│ Doc   … 資料マトリクス（メイン）        │
│ PDF   … PDF を開いて編集               │
│ DM    … 連絡（工事中のこともあり）       │
│ Tax   … 税務進捗ボード                 │
│ カルテ … マスタ・グラフ・給与・進捗など   │
└────────────────────────────────────────┘
```

- **Doc** では左に **永続 / R8 / R7 …** のような「期」の縦リストが出ます。
- **カルテ** では同じ位置に **メモ / マスタ / グラフ …** が縦に並びます（期のドラムの代わり）。

詳しくは [workspace.md](./workspace.md)。

---

## よく使う流れ（例）

1. **Doc** で顧問先と期（例: R8）を選ぶ  
2. スロットに PDF を入れる／開く  
3. 必要なら **PDF** 面やビューアで注釈・並べ替え  
4. 作業内容を保存（ログイン後は事務所サーバー側。Drive は任意ミラー。詳細は [saving.md](./saving.md) · [storage-story.md](./storage-story.md)）  
5. 顧客の数字・メモは **カルテ** で確認・入力  

---

## ゲストの PDF だけ使う場合

ログインなしの `/pdf` もあります。編集はできますが **サーバーには保存されず**、端末へのダウンロードが中心です。社内共有・版管理にはログイン後の Doc／格納を使います。
