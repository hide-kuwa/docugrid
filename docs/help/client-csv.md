# 顧客一覧 CSV

要約: 事務所設定の **顧客マスタ** で CSV を取り込み・書き出しできます。本格稼働の最初の一歩です。取り込んだあとは必ず **保存** してください。列は `id,name,fiscal_month,category,tags` です。

対象: 所長・事務所設定担当（`settings.manage`）

---

## できること

1. **サンプル CSV** をダウンロードして書式を確認する  
2. 事務所の顧問先一覧を同じ列で用意する  
3. **CSV を取り込む**（既存とマージ / CSV で置き換え）  
4. **法人／個人の新規登録**（画面上で1件追加）  
5. 内容を確認して **顧客マスタを保存**  
6. 必要なら書き出してバックアップ  

画面の入り口: **事務所設定 → 顧客マスタ** を一番下までスクロールした **受け入れ・一括取込**（本格稼働バナーからも開けます）  
顧問先カードをクリックすると **顧客詳細** に飛び、その顧問先が選ばれます（名前・決算月の入力欄はカード上でそのまま編集可）。  
一覧は **検索・担当者・決算月・法人/個人** で絞り込めます。  
初回 ZIP 整理は顧客マスタには出しません。本格稼働バナーの **整理パネルを開く** から使います。

---

## 列の意味

| 列 | 必須 | 説明 |
|----|------|------|
| `id` | 任意 | 空なら自動採番。既存とマージするときは揃える |
| `name` | 必須 | 顧問先名（マトリクスの行ラベル） |
| `fiscal_month` | 任意 | 決算月 1–12（省略時: 法人は 3、個人は 12） |
| `category` | 任意 | `corporate` / `individual`（個人） |
| `tags` | 任意 | `\|` や `,` 区切り |

---

## できないこと・注意

- 取り込みだけではサーバーに残りません。**保存**が必要です  
- 関係グループやカルテ詳細は CSV 対象外です  
- **サンプル CSV / 書き出し** は Excel で文字化けしないよう UTF-8（BOM 付き）です。Excel で保存した CSV（Shift-JIS）も取り込めます  

ガイド: 左レール **ヘルプ** → **本格稼働の最初の2歩**
