# カルテ・家系図

要約: カルテ左の **家系図** で、世代（親・子と兄弟姉妹・孫）ごとに家族カードを並べた家系図を作ります。カードには続柄・氏名・フリガナ・生年月日・年齢（自動計算）・職業・同居/別居・別居時住所が載ります。家族のうち顧問先（個人）の人はカードを **顧問先にひも付け** でき、顧問先でない家族は名前だけで登録できます。被相続人を選ぶと **法定相続人と相続分**・**基礎控除** を表示し、**PDF**（A4）や **永続へ保存** もできます。

対象: 担当スタッフ（閲覧は顧問先の閲覧権限、編集・保存は設定管理権限）

---

## 開き方

1. レール **カルテ**
2. 左の縦リストで **家系図**
3. 初回は **本人から始める**（個人の顧問先なら本人として自動でひも付け）か **空のカードを追加**

---

## 編集

| 操作 | 内容 |
|------|------|
| **カードをクリック** | 右の編集欄にその人の項目が出る |
| **顧問先にひも付け** | 顧問先（個人）を検索して選ぶ。氏名は顧客マスタの名前で表示され、フリガナも補完 |
| **＋配偶者 / ＋子 / ＋兄弟姉妹** | 選んだ人を基準に、親・世代を自動設定したカードを追加 |
| **← / →** | 同じ世代の中で並び順を変更 |
| **故人** | 没年月日を入れると年齢欄が「享年」になる |
| **保存** | 変更があるときだけ表示。押すまでサーバーには残りません |

親は最大 2 人、配偶者は 1 人まで指定できます。親は自分より上の世代の人だけ選べます。

---

## 法定相続人

**被相続人** を選ぶと、民法の順位（配偶者＋第 1 順位: 子・代襲 / 第 2 順位: 直系尊属 / 第 3 順位: 兄弟姉妹・甥姪）で相続人と法定相続分を表示します。カードにも「相続人 1/4」などのバッジが付きます。

- 相続税の **法定相続人の数**（養子は実子がいれば 1 人、いなければ 2 人まで）と **基礎控除**（3,000 万円 + 600 万円 × 人数）も表示
- 相続放棄・欠格・廃除、遺言、半血の甥姪の細かいケースは反映しません。最終判断は戸籍で確認してください

---

## PDF / 永続保存

| 操作 | 内容 |
|------|------|
| **縦 / 横** | A4 の用紙向き |
| **PDF** | 家系図と相続人の要約を A4・1 ページでダウンロード |
| **永続へ保存** | 同じ PDF を Doc の **永続** スロット **家系図** に保存。上書きのたびに版が増えます |

---

## 関係図との違い

**関係** の「家系」は顧問先どうしのつながり線です。**家系図** は顧問先でない家族も含めた、相続・申告向けの世代別の表です。両方とも残しています。
