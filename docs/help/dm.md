# DM（連絡）

要約: レールの **DM** はメール／Slack／LINE などをまとめて見る連絡ハブの置き場です。機能によっては **工事中** 表示のままです。急ぎの連絡は既存のメール等を使い、DocuGrid 内 DM に依存しすぎないでください。

対象: 担当スタッフ

---

## いまの位置づけ

- 左レールに **DM** があります  
- 統合受信箱として育てる予定ですが、チャネル接続や通知は設定・権限に依存します  
- 「工事中」と出ている操作はまだ本番利用しないでください  

関連する設定の一部: 通知連携（メール / Slack / LINE）は設定画面側にあります（環境による）。

---

## 困ったとき

資料のやり取りは当面 **Doc の資料** と **メール** を正とします。  
DM の不具合や要望は、将来の AI サポート／CS メールで「DM」と書いてください。→ [support.md](./support.md)
