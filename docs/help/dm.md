# DM（連絡）

要約: レールの **DM** は、この顧問先向けの **システム内チャット** と、メール／Slack／LINE の受信箱です。文書作成では保存後の **シェア** から、必要なときだけ送れます。

対象: 担当スタッフ

---

## いまの位置づけ

- 左レールに **DM** があります  
- **システム**: DocuGrid 内の連絡。外部キー不要  
- **メール / Slack / LINE**: 接続すると同じ受信箱に並びます（設定 → 通知連携）  

関連: 文書のシェア手順は [authoring.md](./authoring.md)。

---

## システム内チャット

1. 顧問先を選んだ状態でレール **DM** を開く  
2. 左のフィルタで **システム**（または **すべて**）  
3. 下部の送信先チャネルを **システム** にして本文を送る  

文書作成の **シェア → システム内 DM** でも、同じ場所に「〜をお渡し」と資料への参照が残ります。スレッドの **資料を開く** で PDF を取れます。

---

## 困ったとき

外部送信（本物の Slack / メール）は接続と権限が必要です。未接続でもシステム内チャットは使えます。  
不具合や要望は AI サポート／CS メールで「DM」と書いてください。→ [support.md](./support.md)
