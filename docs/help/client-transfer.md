# 顧問先の移管コード

要約: 税理士変更などで **顧問先1件** を次の事務所へ渡すとき、移管コードと顧客向け短い URL を使います。マスタ・プロフィール・格納 PDF をパックし、顧客はログインなしでコードを確認、新事務所はコード入力で取り込みます。

対象: 事務所設定権限（`settings.manage`）のあるスタッフ

---

## 旧事務所（渡す側）

1. **事務所設定 → 顧客詳細** で対象顧問先を開く（顧客マスタのカードから詳細へも可）  
2. 画面を一番下までスクロールし、**めったに使わない操作** の **移管コードを発行**  
3. 表示されたコード／URL を顧客（または新事務所）へ渡す  
3. 表示された **URL**（例: `/handoff/AB12CD34`）を顧客に伝える  
4. 不要になったら **取消**（受付前のみ）

顧客向けページには顧問先名とコードだけ出ます。e-Tax 暗証番号などは出ません。

## 顧客

1. 受け取った URL を開く（ログイン不要）  
2. 移管コードを確認・コピー  
3. **新しい税理士**にコードを伝える  

## 新事務所（受け取る側）

1. **事務所設定 → 顧客マスタ** を一番下までスクロールし、**受け入れ・一括取込** の **移管コードで受け取る**  
2. コードを入力 → **プレビュー** → **取り込む**  
3. 顧客マスタに新しい顧問先 ID で追加されます（資料も可能な範囲で複製）

同じ事務所内への移管、期限切れ・取消・使用済みコードは受け付けません。有効期限は発行から **14日** です。

## できないこと（v1）／今後の課題

v1 では次は **あえてやっていません**。運用上重要になりやすいので、詳細と実装案は [`docs/client-transfer-next.md`](../client-transfer-next.md) に残しています。

| 項目 | いま | なぜ残すか |
|------|------|------------|
| 顧客アカウントログインでのコード表示 | 公開 URL のみ | URL 拡散時の露出を減らす |
| Drive ミラーの自動付け替え | しない（再ミラーは手動） | 旧 Drive に正本が残り権限・二重保管のリスク |
| 旧事務所からの物理削除／自動請求停止 | 旧データは残す・請求連動なし | 委託終了後の保管・二重請求の穴 |

できないことだけ見る場合の最短メモ:

- Drive ミラーの自動付け替え  
- 旧事務所データの自動削除・請求停止  
- 顧客アカウントログインでのコード表示
