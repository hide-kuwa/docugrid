# ゲスト PDF（ログイン不要）

要約: `/pdf` はログインなしで注釈・並べ替え・ダウンロードできます。**サーバー保存はありません。** 事務所の資料として残すならログイン後の Doc／PDF から格納してください。

対象: 社内外で「まず PDF だけ触りたい」人

URL の **`/pdf`** から、ログインなしで PDF を開いて注釈・並べ替え・ダウンロードできます。

---

## できること / できないこと

| できる | できない |
|--------|----------|
| 端末上での編集・並べ替え | 事務所サーバーへの保存・版管理 |
| PDF ダウンロード | 他メンバーとのリアルタイム共有 |
| 同タブ内の下書き再開 | ブラウザを閉じたあとの復元（保証なし） |

顧問先のマトリクスに残すには、ログイン後の **PDF** または **Doc** から開いて **格納／作業保存** してください。→ [saving.md](./saving.md)

---

## よくある誤解

- 「ゲストで編集したから Doc に残る」→ **残らない**  
- 「ダウンロードすれば事務所共有」→ **自分の端末だけ**  

---

## 社内 LAN で他 PC から使う（開発時）

ホスト PC で LAN 用の開発サーバーを起動し、ファイアウォールでポートを開けます。  
詳しいコマンドは開発向け `docs/dev-quickstart.md` およびリポジトリの `npm run dev:lan` 系を参照。
