# カルテ · 進捗

要約: カルテの **進捗** は、その顧問先の申告・資料・アラート・納税カレンダーを見る画面です。判定フローチャートはレールの **判定** です。事務所横断の一覧はレール **Tax**、資料の枠の充足は **Doc** のスロットです。

対象: 担当スタッフ

---

## 開き方

**カルテ** → 左縦リストの **進捗**

一部ブロックは工事中表示のことがあります。その場合は表示どおり「参考」にとどめてください。

---

## 他画面との関係

| 画面 | 見るもの |
|------|----------|
| **Doc** | その期の資料スロットが埋まっているか |
| **カルテ → 進捗** | 顧問先単位のマイルストーン・アラート・カレンダー |
| **判定** | 課税事業者などのフローチャート → [flowchart-templates.md](./flowchart-templates.md) |
| **Tax** | 事務所横断の税務進捗ボード → [tax-progress.md](./tax-progress.md) |

資料不足のアラートが出たら、まず **Doc** で該当期の空スロットを確認するのが定石です。

判定の実行と作成はレールの **判定** です。進捗からは案内だけ出ます。

---

## よくある操作

1. 顧問先を選び **進捗** を開く  
2. 判定が必要ならレールの **判定** へ  
3. 赤・黄などのアラートがあれば内容を読む（資料不足／期限／手動メモ）  
4. 資料系なら **Doc** へ飛んでスロットを埋める／要確認を処理  
5. カレンダーで納税・提出の目安日を確認する  

手動アラートを足せる場合は、「いつ・何が・誰向けか」を短く書いてください。後から本人以外が読んでもわかる文が望ましいです。

---

## うまくいかないとき

| 症状 | まずやること |
|------|----------------|
| 全部空／工事中 | 機能未開放の可能性。Tax ボードと Doc で代替確認 |
| アラートが消えない | 原因の Doc スロットや期が違う可能性。対象期を再確認 |
| Tax と数字が違う | 顧問先単位（ここ）と事務所横断（Tax）の集計タイミング差。どちらが新しいか更新時刻を見る |
| 更新ボタンが無い | 自分の役割では閲覧のみのことがあります |

困ったら [faq.md](./faq.md) とサポートチャットへ。
