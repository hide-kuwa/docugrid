# スロットの PDF 以外・画像の PDF 化

要約: Doc の枠には PDF だけでなく Excel・Word・画像なども保存できます。ビューワーで開くのは PDF だけです。png/jpeg などは枠をクリックすると PDF 化し、元ファイルは版履歴からダウンロードできます。

対象: 担当スタッフ（資料を枠に入れる人）

---

## できること

- **保存・ダウンロード:** PDF / 画像（png・jpg・webp・gif）/ Office（xlsx・xls・csv・docx・doc・rtf）
- **閲覧:** PDF のみ（枠クリックでビューワー）
- **画像 → PDF:** 画像が入っている枠をクリック → **PDF 化して開く**（新版が現在版になる）
- **元画像:** 版履歴からダウンロード可能

---

## 手順（最短）

1. Doc で顧問先・期を選ぶ  
2. 空の枠にファイルをドロップ（または選択）  
3. **PDF** → いつもどおりビューワーで開く  
4. **画像** → 枠をクリック → PDF 化のあとビューワー  
5. **Excel など** → 枠をクリック → ダウンロードのみ  

---

## できないこと

- Excel / Word の画面内プレビュー
- Office の自動 PDF 変換
- exe・ZIP など許可外形式のアップロード
- 自動振り分け（まとめて分類）への PDF 以外の投入（分類は PDF のみ）

---

## 初回 ZIP 整理との関係

ZIP に PDF 以外を含めると、分類なしで **要確認キュー** に入ります。顧問先・期間が分かれば確定して枠へ保存できます。ビューワーで見たい画像は、マトリクス上で後から PDF 化してください。
