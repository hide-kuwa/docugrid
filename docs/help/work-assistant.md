# DocuGrid AI（業務アシスタント）

要約: Doc 画面・設定画面の右下から開けるチャットです。使い方の質問、いまの顧問先・期の資料充足確認、OCR 抽出結果のマスタ反映（確認後のみ）、顧問先資料のキーワード／ベクトル検索ができます。

対象: ログイン中のスタッフ（`admin@taxx.jp` 含む）

---

## 開き方

- **Doc（資料マトリクス）** 右下の丸いチャットボタン → DocuGrid AI
- **設定** 画面でも同じボタンが出ます（プラットフォーム管理者向け）

ヘッダーに、いま選んでいる顧問先と期が表示されます（設定画面では顧問先未選択のことがあります）。

---

## できること

| 聞くこと（例） | 動き |
|----------------|------|
| 「このクライアント資料揃ってる？」 | いまのレイアウトの枠と保存済み資料を比較。不足一覧を表示 |
| 「OCRして基本情報に反映して」 | 抽出できる項目があればカード表示 → **反映する** でマスタへ（確認前は書かない） |
| 「源泉徴収票を探して」 | 選中の顧問先の索引から抜粋を返す（firm 内のみ。埋め込み + キーワード） |
| 「自動振り分けの使い方」など | ヘルプ記事から回答。リンクでヘルプを開ける |

ショートカットボタンもパネル内にあります。

PDF を枠へ上げると、取り出せるテキストはすぐ索引に入ります。スキャンのみの資料は OCR 完了後にヒットします。特定個人情報は索引しません。

設定 → MCP タブの **RAG / MCP 社内検索ラボ** でも同じ検索 API を試せます。

---

## できないこと（いま）

- 税務判断の最終回答
- 確認なしのマスタ自動上書き
- 他事務所のデータ参照

---

## ヘルプとの関係

左レールの **ヘルプ** フライアウト内サポートチャットも使えます。右下 AI は業務確認（充足・OCR・資料検索）を同じ場所で足したものです。
