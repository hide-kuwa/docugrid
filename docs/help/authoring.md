# 文書作成（差し込み）

要約: ひな形を選んで甲乙を割り当て、**枠に保存** します。送るときだけ完了画面の **シェア** から、システム内 DM・ポータル・接続済みの Slack / メール / LINE を選びます。Word のような細かい体裁は目的ではありません。

対象: 担当スタッフ

---

## 開き方

1. レールで **Doc** を開き、顧問先を選ぶ  
2. 資料枠の近くの **文書作成**  
3. ひな形（または白紙）を選ぶ  

ひな形の登録はレールの **ひな形**（`/templates`）です。判定フローはレールの **判定** です。設定の「文書ひな形」からも同じ文書エディタを開けます。

---

## 最短の流れ

1. 文書の種類を選ぶ  
2. **当事者１（甲）** / **当事者２（乙）** に顧問先を選ぶ（必要なとき）  
3. ざっと本文を確認する  
4. **枠に保存**  
5. 渡すときだけ **シェア**  

保存だけでは誰にも送られません。

---

## シェアでできること

- **システム内 DM** — 事務所の受信箱（レールの DM → システム）  
- **お客さんのポータル** — お客さん本人が開ける  
- **Slack / メール / LINE** — 通知連携が接続済みのとき  
- **PDF をダウンロード**  

未接続のチャネルはグレーです。接続は **設定 → 通知連携**、または DM のツール設定です。

---

## できること

- マスタから 【法人名１】【宛名１】【和暦本日】 などを差し込む  
- 法人は **御中**、個人は **様**  
- 保存先枠はひな形側で自動（無ければ一覧から選ぶ）  
- 行の **左／中央／右揃え** と **字下げ**（Tab）。折返しでも先頭は揃う  
- 文字間の自動詰めはしない（書いたとおりの字間）  

---

## できないこと

- Word のような段組・表・文字飾りの編集  
- 文字間を自動で詰める／広げる  
- Slack / メールへ PDF 本体を自動添付（本文で枠の場所を知らせ、ファイルは Doc に残る）  
- カルテのマスタに無い項目は空のまま残ります  

---

## うまくいかないとき

| 症状 | 確認 |
|------|------|
| 【法人名２】が残る | 乙を選んでから保存。保存時に自動で差し込みます |
| 住所が空 | カルテの **マスタ** に本店住所があるか |
| Slack などが押せない | 未接続。設定 → 通知連携。送信には通知連携の権限も必要 |
| ひな形が見えない | 設定の文書ひな形と権限 |
