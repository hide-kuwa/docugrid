# 文書作成（差し込み）

要約: ひな形を選び、まず【】や `{{ }}` の**かっこ書き**で整え、**差し込み版**で確認してから **枠に保存** します。送るときだけ完了画面の **シェア** から DM・ポータル・Slack / メール / LINE を選びます。

対象: 担当スタッフ

---

## 開き方

1. レールで **Doc** を開き、顧問先を選ぶ  
2. 資料枠の近くの **文書作成**  
3. ひな形（または白紙）を選ぶ  

ひな形の登録はレールの **ひな形**（`/templates`）です。判定フローはレールの **判定** です。事務所アカウントではこれらのレール項目は出ません（開発者のみ）。

---

## 最短の流れ

1. 文書の種類を選ぶ（開いた直後は **かっこ書き**＝差し込み前）  
2. **当事者１（甲）** / **当事者２（乙／代表取締役など）** を選ぶ（検索可。当事者２は乙の会社でも代表取締役個人でも可）  
3. 本文の 【法人名１】 や `{{representative_name}}` を確認・編集  
4. **差し込み版** でマスタ反映をプレビュー（元のかっこ書きは消えない）  
5. **枠に保存**（保存時に差し込みして PDF 化）  
6. 渡すときだけ **シェア**  

保存だけでは誰にも送られません。

---

## かっこ書き / 差し込み版

| モード | 内容 |
|--------|------|
| **かっこ書き** | 【】や `{{ }}` のまま編集。項目リストから足せる |
| **差し込み版** | 顧問先マスタを当てたプレビュー。編集はかっこ書きに戻る |

編集画面は **左サイド** に当事者・モード・手入力、**右** に書類本文です。  
マスタに無い／空の項目は左の **手入力** に出ます。埋めてから差し込み版を見てください。  
当事者を変えると、差し込み版はいったんかっこ書きに戻ります（再プレビューしてください）。

---

## シェアでできること

- **システム内 DM** — 事務所の受信箱（レールの DM → システム）  
- **お客さんのポータル** — お客さん本人が開ける  
- **Slack / メール / LINE** — 通知連携が接続済みのとき  
- **PDF をダウンロード**  

未接続のチャネルはグレーです。接続は **設定 → 通知連携**、または DM のツール設定です。

---

## できること

- マスタから 【法人名１】【宛名１】【和暦本日】 などを差し込む  
- 法人は **御中**、個人は **様**  
- 保存先枠はひな形側で自動（無ければ一覧から選ぶ）  
- 行の **左／中央／右揃え** と **字下げ**（Tab）。折返しでも先頭は揃う  
- 書類は **拡大／縮小**（ツールバー・Ctrl+ホイール・Ctrl±）。全体ながめや細部確認に使う  
- 文字間の自動詰めはしない（書いたとおりの字間）  

---

## できないこと

- Word のような段組・表・文字飾りの編集  
- 文字間を自動で詰める／広げる  
- Slack / メールへ PDF 本体を自動添付（本文で枠の場所を知らせ、ファイルは Doc に残る）  
- カルテのマスタに無い項目は空のまま残ります  

---

## うまくいかないとき

| 症状 | 確認 |
|------|------|
| カルテに無い項目がある | 黄色い **手入力** 欄に入れる。保存前に未入力があると止めます |
| 【法人名２】が残る | 当事者２を選んでから差し込み版／保存 |
| 住所が空 | カルテの **マスタ** に本店住所があるか |
| Slack などが押せない | 未接続。設定 → 通知連携。送信には通知連携の権限も必要 |
| ひな形が見えない | 設定の文書ひな形と権限 |
| 文字が勝手に増える | かっこ書きのまま編集し、差し込みは **差し込み版** タブで確認 |
