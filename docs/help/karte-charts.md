# カルテ · グラフ

要約: カルテの **グラフ** は売上・利益など顧問先の指標ダッシュボードです。正規の数値と、画面上だけのシミュレーション（試算）が分かれていることがあります。監査チェック連携がある環境では、数値から資料突合へ進めます。

対象: 担当スタッフ

---

## 開き方

**カルテ** → 左縦リストの **グラフ**

---

## 正規値とシミュレーション

| 種類 | 意味 |
|------|------|
| 正規（canonical） | 保存された指標。他機能の前提になりやすい |
| シミュレーション | この画面で試す用。正規を上書きしないことが多い |

画面上で色や差分表示がある場合は、シミュレーション中の可能性があります。保存・確定の操作名は UI のボタンに従ってください。

**正規指標** ブロックは上段が直近3期の表（売上・利益・課税標準・照合）、下段が月次売上指数と月次売上（円）の2カードです。数値があるときだけ照合用の **監査** が出ます。未入力の欄は空欄（プレースホルダ「未入力」）です。

---

## うまくいかないとき

| 症状 | 確認 |
|------|------|
| 数字が空 | 顧問先・期が合っているか／マスタ・取込が済んでいるか |
| 触っても戻る | シミュレーションか正規かの区別 |
| グラフが見つからない | レール **カルテ** → 左の **グラフ**（レールに単独の「グラフ」はない） |

正規値の確定は事務所の運用ルールに従ってください。税務判断の最終決定は別途確認。
