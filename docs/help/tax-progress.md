# 税務進捗（Tax）

対象: 担当スタッフ・所長

レールの **Tax** を開くと、決算・中間・源泉など税務まわりの進捗ボードが出ます。  
**Doc** の資料スロット不足とは別画面ですが、現場ではセットで見ることが多いです。

---

## できること（概要）

- 顧問先横断で、今どこまで進んでいるかを一覧  
- 期限・手動更新の項目がある場合はボード上で確認（環境による）  

細かいステータスの定義は事務所運用に合わせて変わります。不明な列は所長または設定担当に確認してください。

---

## Doc / カルテとの関係

| 画面 | 役割 |
|------|------|
| **Doc** | その期の資料が揃っているか（スロット） |
| **カルテ → 進捗** | 顧問先単位の進捗・アラート寄り |
| **Tax** | 事務所横断の税務進捗ボード |
