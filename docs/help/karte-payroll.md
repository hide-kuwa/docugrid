# カルテ · 給与

要約: カルテの **給与** は、従業員マスタや月次の源泉・給与台帳に近いデータを扱う画面です。まるふや年末調整・算定基礎など、給与まわりをここに寄せていく想定です。法令の最終判断は税理士・社労の確認が必要なことがあります。

対象: 担当スタッフ

---

## 開き方

**カルテ** → 左縦リストの **給与**

権限や事務所設定で一部ブロックが隠れていることがあります。

---

## 最短の見方

1. 顧問先を選び、対象の期・月を確認する  
2. **給与** を開き、従業員一覧／月次行があるか見る  
3. 金額を直すときは、元資料（給与明細・賃金台帳）を **Doc** のスロットと照合する  
4. 確定に近い操作の前に、氏名・支給額・源泉の合計をざっと見直す  

月次入力の細かい項目名は画面ラベルを正とします（事務所によって並びが違います）。

---

## 他画面との関係

| 画面 | 関係 |
|------|------|
| **Doc** | 給与明細・賃金台帳・源泉票の置き場 |
| **カルテ · マスタ** | 法人・代表者など顧問先の基本情報 |
| **Tax** | 源泉・年末まわりの事務所横断進捗 |

給与画面で数字がおかしいときは、まず Doc の該当月スロットが空／古い版でないか確認してください。

---

## 注意

- 誤入力は源泉・社保・年末調整に波及します  
- AI／OCR から取り込んだ値は必ず目視確認  
- 「試算」「下書き」と「確定」が分かれているときは、確定前に所長方針を確認  

---

## うまくいかないとき

| 症状 | まずやること |
|------|----------------|
| 従業員が出ない | マスタ側の登録・権限・別顧問先を見ていないか |
| 月が空 | 対象月の切り替え。Doc に資料だけあって未転記の可能性 |
| 保存できない | 権限・未入力必須項目。エラー文を控えてサポートへ |
| 年末・まるふの導線が見えない | 機能が未開放／工事中のことがあります。事務所管理者に確認 |

電話の前に、ヘルプの [support.md](./support.md) とチャット → メール CS を使ってください。
