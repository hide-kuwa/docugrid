# 資料マトリクス（Doc）

要約: Doc は顧問先×期×スロットで資料を並べるメイン画面です。PDF 以外（Excel・画像など）も枠に保存・DLできます（ビューワーは PDF のみ。画像は枠クリックで PDF 化）。上で顧問先、左で期（R8 など）、中央に資料枠。入れ違いは枠の右クリックで移動。まとめて投入すると自動振り分け／要確認キューもあります。

対象: 担当スタッフ

---

## 画面の見方

- **上** … 顧問先の切替（ログイン中の事務所の**担当分／すべて**。デモ顧客は出ません）。左上の **ロゴ** で Doc トップ（先頭顧問先のドキュメント画面）へ戻ります。右上に**会社名（事務所）とログイン中の氏名**、その右の丸い検索ボタンで名前・ID・かな（ひらがな可）絞り込み  
  左上の **担当分 / すべて** で表示範囲を切り替えられます（現状は全員が全顧問先を見られます。割当設定は事務所設定に残しています）。  
- **左（縦）** … **永続** / **R8・R7…**（決算年）または月次。年度の下に **R〇年〇月期**（顧問先の決算月）と、顧客詳細に設立年月日があるときは **第N期** を表示します  
  （顧問先データ・マスタはレールの **カルテ**。Doc ドラムに「データ」行はありません）
- **中央** … その期の資料スロット（決算書・総勘定元帳など）
- **永続を選んだとき** … 顧問先ナビの直下に横タブ **資料 / 保有 / 提案 / 案件**（CRM 入口）。詳細は [crm-perm.md](./crm-perm.md)

期ラベル（R8 など）は顧問先の決算月に合わせ、**今日から1年後までに期末を迎える期まで**出ます（12月決算でも当年の R8 が出ます）。  
Rn の下の西暦は **期末の西暦** です（R8 → 2026年）。  
年次見出しの「決算資料」の右には、顧問先の決算月と選んだ Rn から自動計算した事業年度（例: `（2025年1月1日～2025年12月31日）`）が出ます。マスタの決算月を変えると、同じ Rn でも期間が追従します。  
開いた直後および **MONTH → YEAR** では、**申告シーズン込みの「今の年度」** へ自動移動します。  
- **法人** … 決算日から2か月後まではその期末の Rn（例: 3月決算 → 5月末まで R8）。過ぎたら進行中の期。  
- **個人** … 3月末までは前年分（申告）、4月以降は当年。ナビ表記は「3月申告」。  
月次は今日の年月へ移動します。  
月次の見出しと左ドラムには **西暦** が付きます（例: 2026年8月）。並びは決算月が一番上で、**年度ドラムと同じ年数分** 前期まで遡れます。見出しの **前期** / **次期** で事業年度を12か月ずつ移せます。  
左上のラベルは **YEAR**（年次・R8）と **MONTH**（月次）が切り替わります。左ドラムのダブルクリックや横スワイプで入れ替わります。

左下ガイドの「資料マトリクス（Doc）」でも同じ場所を光らせます。

## よくある操作

1. 顧問先を選ぶ（多いときは右上検索）  
2. 左で期（例: **R8**）を選ぶ  
3. 空スロットにファイルをドロップ、または既存資料を開く（PDF 以外は [slot-attachments.md](./slot-attachments.md)）  
4. PDF はビューアで確認・注釈・並べ替え後、必要なら作業保存／承認フローへ  

入れ違いのとき: 資料が入った枠を **右クリック** → **枠を変更** / **期（年度）を変更** / **顧問先を変更**。行き先に既に資料があるときは先に空にしてください。  
不要な資料は同じメニューの **資料を削除**（枠は残ります。削除済み一覧から復元できる場合があります）。  
不要な資料は同じメニューの **資料を削除**（枠は残ります。削除済み一覧から復元できる場合があります）。  

複数 PDF をまとめて入れるときはスロットへドロップ → [auto-sort.md](./auto-sort.md)。  
マトリクス下部のステータス・不足バー・申告パッケージ帯は当面非表示です（振り分け・不足計算はそのまま動きます）。要確認が残ったときだけキューが出ます。  
契約書や送付状をマスタから差し込むときは枠近くの **文書作成** → [authoring.md](./authoring.md)。

## うまくいかないとき

| 症状 | 確認 |
|------|------|
| 上のドラムがデモ顧客のまま | 取込先と同じ事務所（例: PROLEXT）でログインしているか。再読み込み後も空なら担当割当 |
| 上のドラムが空 | 担当顧問先がまだ無い。所長は事務所の顧客が出る。スタッフは設定の担当マスタ |
| 探している顧問先が出ない | 右上の検索語を消す／担当分→すべて |
| YEAR（R8）のドラムが開かない | 左ドラムをダブルクリック（または横スワイプ）。上のラベルが **YEAR** なら年次（R8・R7…）、**MONTH** なら月次 |
| 枠に入らない | 要確認キューに残っていないか |
| マスタ／メモを探している | レールの **カルテ**（Doc の左ドラムには出ません） |
