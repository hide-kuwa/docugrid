# 資料マトリクス（Doc）

要約: Doc は顧問先×期×スロットで PDF を並べるメイン画面です。上で顧問先、左で期（R8 など）、中央に資料枠。まとめて投入すると自動振り分け／要確認キューもあります。

対象: 担当スタッフ

---

## 画面の見方

- **上** … 顧問先の切替など（ナビ）
- **左（縦）** … **永続** / **R8・R7…**（決算年）または月次  
  （顧問先データ・マスタはレールの **カルテ**。Doc ドラムに「データ」行はありません）
- **中央** … その期の資料スロット（決算書・総勘定元帳など）
- **永続を選んだとき** … 顧問先ナビの直下に横タブ **資料 / 保有 / 提案 / 案件**（CRM 入口）。詳細は [crm-perm.md](./crm-perm.md)

期ラベル（R8 など）は顧問先の決算月に合わせて並びます。  
月次モードでは **決算月が一番上**（例: 3月決算 → 3月・2月・…・4月）です。  
サイドバーのダブルクリックや横スワイプ相当で **年 ↔ 月** を切り替えられる場合があります。

左下ガイドの「資料マトリクス（Doc）」でも同じ場所を光らせます。

---

## よくある操作

1. 顧問先を選ぶ  
2. 左で期（例: **R8**）を選ぶ  
3. 空スロットに PDF をドロップ、または既存資料を開く  
4. ビューアで確認・注釈・並べ替え後、必要なら作業保存／承認フローへ  

複数 PDF をまとめて入れるときは投入エリアへ → [auto-sort.md](./auto-sort.md)。

---

## うまくいかないとき

| 症状 | 確認 |
|------|------|
| 資料が見えない | 顧問先・期が合っているか |
| 枠に入らない | 要確認キューに残っていないか |
| マスタ／メモを探している | レールの **カルテ**（Doc の左ドラムには出ません） |
