# マイナンバー関連書類の扱い

**要約:** 個人番号が載った PDF は **「特定個人情報」フラグ** か **SPI 専用 API** で入れます。暗号化され、Drive や AI には流れません。閲覧には専用権限が必要です。

対象: 所長・事務取扱担当者  
関連: [マイナンバー取扱い（HP／設計）](../my-number-handling.md) · [保存の話](./storage-story.md)

---

## できること

- 番号入り書類を通常資料と分けて保管する  
- 権限のある人だけが開く  
- 保存期間の目安（既定 7 年）を付けて、あとで廃棄できる  

## できないこと／やらないこと

- Google Drive への自動ミラー  
- AI 自動振り分けへの投入  
- 顧問先ポータルへの共有  

## 現場での使い方（最短）

1. 扶養控除等申告書など番号入り PDF を用意する  
2. アップロード時に **個人番号を含む** として登録する（または SPI 専用の保管 API）  
3. 開けるのは `my_number.view` があるロールだけ  
4. 保存が終わったら、方針に従い削除／廃棄する  

権限の付与は事務所管理者のロール設定で行います（既定では事務所管理者・オペレータ等）。

## 迷ったら

| 状況 | 対応 |
|------|------|
| 番号が載っていない一般の申告書 | 通常の資料スロットでよい |
| Drive に出てこない | 仕様です（SPI はミラーしません） |
| スタッフが開けない | ロールに `my_number.view` があるか確認 |
