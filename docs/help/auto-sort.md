# 自動振り分け・要確認キュー

要約: Doc で複数 PDF をまとめて落とすと、書類種別を推定してスロットへ入れます。自信があるものは自動配置、弱いものは **整理トレイ（要確認）** で人が確定します。枠を消したあとの **未割当** も同じトレイから振り分けます。

**現状（2026-09）:** マトリクス右端の **まとめて自動振り分け** ドロップ帯とスマホの一括ボタンは **当面非表示** です。個別スロットへのドロップは従来どおり使えます。

対象: 担当スタッフ（資料をまとめて入れる人）

画面スケッチ（Doc）:

```
┌ 上: 顧問先 ──────────────┐
│ 左: R8 等 │ [整理トレイ]     │  ← 要確認＋未割当
│           │ [自動振り分け帯] │
│           │ 中央: スロット群 │
└───────────┴────────────────┘
```

左下 **ガイド → 自動振り分け** でも同じ場所を光らせます。

---

## 自動振り分けとは

**Doc** のマトリクスで、複数 PDF をまとめてドロップすると、書類の種類を推定してスロットへ振り分けます。  
確信度が高いものはそのまま枠へ。低いものは **整理トレイ（要確認）** に回ります。

---

## 手順（最短）

1. レールで **Doc** を開く  
2. 上で **顧問先**、左で **期**（例: **R8**）を選ぶ  
3. スロット群へ PDF を複数ドロップ  
4. 自動で入ったスロットのラベルをざっと確認  
5. **整理トレイ** に残ったものは、**提案どおり確定** または枠名を検索してクリック  

---

## 確信度の目安（感覚）

画面に「確信度 ○○%」と出ることがあります（実装・モデルにより表記は変わります）。

| 目安 | 起きやすいこと | あなたがすること |
|------|----------------|------------------|
| 高い | そのままスロットへ | ラベルが妥当か一目確認 |
| 低い／迷い | 整理トレイ（要確認）へ | 提案どおり、または正しい枠を選んで確定 |
| 失敗・上限 | 画面メッセージ | メッセージを優先。ページ数・権限を確認 |

「高い＝正しい」ではありません。似た帳票・スキャン品質・ファイル名で誤ることもあります。

---

## 整理トレイ {#要確認キュー}

スロット直上に出る作業台です。**要確認**（自動振り分けで迷った PDF）と **未割当**（枠削除などで枠から外れた PDF）をまとめて振り分けます。

- 件があるときだけ表示（0 件なら非表示）  
- 左でファイルを選び、右で **提案どおり確定** / 枠検索 / 開く / 破棄（要確認）/ 削除（未割当）  
- キーボード: トレイにフォーカスがあるとき **↑↓** で前後、**Enter** で提案どおり  
- 放置すると資料がスロットに載らないので、**定期的に空にする**運用がおすすめです  

---

## うまくいかないとき

| 症状 | まず疑うこと |
|------|----------------|
| 枠に入らない | 整理トレイに残っていないか |
| 投入エリアが無い | Doc か／アップロード権限か／期が選ばれているか |
| 全部キューに行く | スキャンが粗い・種類が特殊・スロット定義と合っていない |
| 権限エラー | 所長にアップロード権限を確認 |
| ページ数・サイズエラー | 画面のメッセージと上限に従う |

取り消し・やり直しは、トレイから破棄して入れ直すか、誤って入ったスロット側の運用（削除／差替え）に依存します。不明なら所長または設定担当へ。

---

## できないこと

- 税務上の最終判断（枠に入った＝正しい申告、ではありません）  
- 権限のない顧問先への投入  
- ゲスト `/pdf` からの事務所マトリクス自動振り分け  
- このトレイから別の顧問先・別の期への移動（同じ顧問先・同じ期内の枠へ）
