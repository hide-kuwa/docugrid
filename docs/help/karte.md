# カルテ

要約: レールの **カルテ** は顧問先データのハブです。左の縦リスト（Doc では R8・R7 があった場所）で **メモ／マスタ／グラフ／進捗／給与／株評／特殊** などを切り替えます。上の横タブではありません。左下ガイドの「カルテの見方」でも同じ流れを光らせます。

対象: 担当スタッフ

---

## 開き方

1. 左の ≡（レール）を開く／固定する  
2. **カルテ** を選ぶ  
3. 左の縦リストでセクションを選ぶ  

画面スケッチ:

```
≡ Doc PDF Tax │ メモ │
              │ マスタ│  ← Doc の「R8」と同じ縦位置
              │ グラフ│
              │ …    │     中央: 選んだセクションの内容
```

---

## 左の項目

| 左の項目 | 内容 | 詳細ヘルプ |
|----------|------|------------|
| **メモ** | 打合せ宿題・期末メモ・永続の注意点 | 下記「メモ」 |
| **マスタ** | 顧客マスタ・正規化データ | [karte-master.md](./karte-master.md) |
| **関係** | 家系・出資・紹介の関係図 | [karte-relations.md](./karte-relations.md) |
| **グラフ** | 売上・利益などのダッシュボード | [karte-charts.md](./karte-charts.md) |
| **進捗** | 申告進捗・課税判定フロー・税務アラート・納税カレンダー | [karte-progress.md](./karte-progress.md) |
| **給与** | 源泉徴収簿・従業員マスタ | [karte-payroll.md](./karte-payroll.md) |
| **株評** | 自社株評価の試算 | [karte-stock.md](./karte-stock.md) |
| **特殊** | 対応上の注意・特例 | [karte-special.md](./karte-special.md) |
| **連絡** / **調査** | やり取り・調査履歴（環境により工事中） | — |

---

## メモ（KARTE）について

- 区分: 宿題 / 期ごと / 期末 / ずっと残す、など  
- 後から社内検索（RAG）に載せることもできます（権限・設定による）  
- 期が必要な区分では、**Doc で選んでいる期が初期値**になることがあります  

---

## Doc / Tax との役割分担

| 画面 | 役割 |
|------|------|
| **Doc** | その期の **資料 PDF** が揃っているか |
| **カルテ** | 顧問先の **数字・メモ・マスタ** など |
| **Tax** | 事務所横断の税務進捗ボード → [tax-progress.md](./tax-progress.md) |
| **カルテ → 進捗** | 顧問先単位の進捗・アラート寄り |

「資料が無い」はまず Doc。「顧客の注意点・マスタ」はカルテ、と覚えると迷いにくいです。

---

## うまくいかないとき

| 症状 | 確認 |
|------|------|
| 左がまだ R8・R7 | レールで **カルテ** を選べているか（Doc のまま） |
| マスタ等が見つからない | 左縦の **マスタ** を選ぶ（レールにマスタ単独は出ない） |
| メモの期が違う | Doc 側の期を合わせてからメモを開く |
| 連絡・調査が工事中 | 環境により未公開。無理に使わない |

---

## できないこと（いま）

- カルテから自動で申告書 PDF を完成させること（資料ハブ・メモ・マスタ寄り）  
- 会計仕訳の本体操作（別プロダクト）
