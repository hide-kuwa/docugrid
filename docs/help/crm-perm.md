# 永続の保有・提案・案件（CRM）

要約: Doc の左で **永続** を選ぶと、顧問先ナビの直下に横タブ **資料 / 保有 / 提案 / 案件** が出ます。資料は従来の永続スロット。保有・提案・案件は保険や不動産などの商談状態を見る入口です（いまは骨格・プレビュー）。

対象: 担当スタッフ

---

## 開き方

1. レール **Doc**  
2. 左の期ドラムで **永続**  
3. 顧問先ナビ直下の横タブを切り替える  

年度（R8 など）ではこの横タブは出ません。

---

## タブの意味

| タブ | いま見えるもの | これから |
|------|----------------|----------|
| **資料** | 永続の PDF スロット（いままでどおり） | 変更なし |
| **保有** | プレースホルダ | 契約中の保険など＋証券への導線 |
| **提案** | プレースホルダ | 提案書・見積・設計中の資料 |
| **案件** | プレースホルダ | 進捗中の商談一覧（保険・不動産共通） |

左に「保険」行は増えません。状態は永続の中だけで切り替えます。

---

## できないこと（現状）

- 商談の登録・ステージ更新（API 未接続）  
- 保有／提案からの実データ一覧  

方針の正本: 開発向け `docs/crm-packs-vision.md`
