# スマホ・タブレットで使う

要約: DocuGrid はまず **PC での整理** を前提にしていますが、iPhone などでも **資料の閲覧・簡易アップロード・顧客向けページ** は使えるよう整えています。スマホでは余白を詰め、ブランド緑の主ボタンで上げる導線にしています。

対象: 出先のスタッフ、顧問先（ゲスト）

---

## 方針（いまできること）

| 用途 | スマホ | メモ |
|------|--------|------|
| Doc で資料を見る・開く | ○ | 期間は上部チップ → ドロワー |
| PDF をまとめて上げる | ○ | 画面下の **PDFをまとめて上げる** |
| マスタの確認・軽い編集 | △ | 閲覧は可。細かい編集は PC 推奨 |
| ゲスト `/pdf` | ○ | ログイン不要。端末上のみ |
| 移管 `/handoff/…` | ○ | コードコピー／共有 |

---

## スタッフ（ログイン後）

1. Safari / Chrome で [app.taxx.jp](https://app.taxx.jp) を開く  
2. 左端の細いバーをタップ → Doc / カルテ などを切替  
3. 上部の期間チップで Rn やカルテ節を選ぶ  
4. 資料を上げるときは下の **PDFをまとめて上げる**（自動振り分け）

ホーム画面に追加（「ホーム画面に追加」）すると、ノッチ周りも見やすくなります。

---

## 顧客・ゲスト

- **PDF だけ触る:** `/pdf` → [guest-pdf.md](./guest-pdf.md)  
- **移管コードを見る・渡す:** `/handoff/コード` → [client-transfer.md](./client-transfer.md)
