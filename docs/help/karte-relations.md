# カルテ・関係（家系・出資・紹介）

要約: カルテ左の **関係** で、いま選んでいる顧問先を中心に関係図を見ます。上の切替で **全体 / 出資 / 家系 / 役員 / グループ / 紹介** に絞れます。個人が法人の社長・役員なら **役員・代表** で登録すると役職名付きの線で出ます。ノード・ラベル・矢印（曲線）はドラッグで動かせます。名前をクリックするとその顧問先を中心に切り替えます。**縦 / 横**（A4）を選んで **PDF** や **永続へ保存** ができます。

対象: 担当スタッフ（編集・保存は権限がある人）

---

## 開き方

1. レール **カルテ**  
2. 左の縦リストで **関係**  
3. 上のパターン（全体・出資・家系・グループ・紹介）を選ぶ  
4. 右の **つながり** で現状の関係を確認／追加  
5. 用紙向き **縦** / **横**（A4）を選ぶ  
6. 必要なら **PDF** ダウンロード、または **永続へ保存**  

顧問先ナビで別の顧問先に切り替えると、図の中心が変わります。図上の名前を **クリック** しても同様に中心を切り替えられます（ドラッグすると位置だけ動きます）。

---

## 図の操作

| 操作 | 内容 |
|------|------|
| **ノードをドラッグ** | 顧問先ボックスを移動（矢印も追従） |
| **ラベルをドラッグ** | 「出資 60%」などの文字を移動 |
| **矢印をドラッグ** | 線の中点ハンドルでカーブを調整 |
| **名前をクリック** | その顧問先を中心にした図に切替 |
| **配置を戻す** | 手動で動かした位置を初期レイアウトに戻す |

手動配置は顧客マスタに保存され、**PDF / 永続へ保存**にも同じ配置が載ります。「配置を戻す」でそのパターンの手動配置を消します。

---

## 表示パターン

| パターン | 見えるもの |
|----------|------------|
| **全体** | 会社グループは枠のみ。線は親族・出資・役員・紹介（グループ線は出さない） |
| **出資** | 出資関係図のみ（％付き） |
| **家系** | 親族の家系図のみ |
| **役員** | 社長・役員だけ（誰がどの法人の代表か） |
| **グループ** | 同一グループの枠のみ（会社・親族グループなど） |
| **紹介** | 紹介元・被紹介の線のみ |

---

## PDF / 永続保存

| 操作 | 内容 |
|------|------|
| **縦 / 横** | A4 の用紙向き。関係図は横長なので初期は **横** |
| **PDF** | 余白付き A4・1 ページ（凡例・タイトル付き）をダウンロード。プリンタの「用紙サイズ A4」でそのまま印刷しやすい |
| **永続へ保存** | 同じ A4 PDF を Doc の **永続** スロット **関係図** に保存。上書きのたびに **版（Ver）** が増えます |

Doc で左の **永続** を開き、スロット **関係図** を見ると最新版が開きます（履歴はビューアの版一覧から）。

---

## 線と枠の意味

| 表示 | 意味 |
|------|------|
| **青い四角枠** | 会社グループの範囲（全体では会社グループのみ。親族グループは「グループ」切替） |
| **紫の線（オープン矢印）** | 親族 |
| **緑のダーツ矢印＋％** | 出資（誰→誰・持分） |
| **赤紫のダーツ矢印＋役職** | 役員・代表（個人 → その法人）。線の文字は入力した役職名 |
| **オレンジ破線＋ダーツ「紹介」** | 紹介元 → 被紹介 |
| **角のゆるいノード** | 法人 |
| **少し丸いノード** | 個人 |

---

## 編集（権限がある場合）

右の **つながり** 見出し横の **追加** を押し、種別・From・To・（出資なら％）・メモを入れて登録します。From / To の顧問先は **名前・かなで検索** して絞り込めます。一覧のゴミ箱で削除できます。

社長・役員は種別 **役員・代表** を選び、**From に個人**（例: 大房 明良）、**To にその法人** を指定します。**役職**（代表取締役など）を入れると、そのまま図の線に出ます。同じ人が複数社の代表なら、法人ごとに 1 本ずつ登録してください。  
関係データの保存先は顧客マスタ（`client-master`）。PDF の保存先は永続スロットです。

---

## できないこと（現状）

- 履歴事項全部証明書からの株主・役員の自動抽出（役員は手入力）  
- 顧問先マスタにない相手（見込みのみ）のノード  
- ドラッグで自由配置する編集
