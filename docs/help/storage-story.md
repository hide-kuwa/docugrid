# 資料はどこに残る？（サーバー ＋ Google Drive）

**要約:** DocuGrid は **まずサーバーに保存**し、設定が ON なら **Google Drive にも同じ PDF を残します**。ブラウザや個人 PC に勝手に溜まるアプリではありません。Drive だけが正本になる設計ではなく、**事務所のマトリクス・権限・版管理は DocuGrid が正**です。

対象: 所長・運用担当・これから導入を検討している人  
LP・営業資料向けの文章もこのページの下にまとめています。

関連: [保存先について](./saving.md) · [Google Drive 連携](./google-drive.md) · [初回データ整理](./migration.md) · [マイナンバー](./my-number.md)

---

## 30秒でわかること

1. スタッフが DocuGrid に PDF を入れる → **必ず事務所のサーバーに保存**される  
2. Google Drive 連携を ON にしている → **同じファイルを Drive にもコピー**（ミラー）※**マイナンバー関連は例外でミラーしない**  
3. スタッフ同士は **DocuGrid 上で同じ顧問先・同じ期**を見れば共有される  
4. **Drive がパンパンでも**、サーバーへの保存は通常続く（Drive へのコピーだけ失敗することがある）

## イメージ（人向けの図）

```
┌─────────────────────────────────────────────────────────┐
│  税理士事務所のスタッフ（ブラウザ）                      │
│    資料マトリクスへ投入・格納・初回 ZIP 整理             │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
              ┌─────────────────────────┐
              │  DocuGrid サーバー       │  ← いつもここが「運用の正」
              │  ・PDF 本体              │     マトリクス・版・権限
              │  ・どの顧問先・どの期か  │
              └────────────┬────────────┘
                           │ 連携 ON のときだけ
                           ▼
              ┌─────────────────────────┐
              │  事務所の Google Drive   │  ← 正式保管・バックアップ
              │  （共有ドライブ推奨）    │     所内から Drive で見る用
              └─────────────────────────┘
```

**ポイント:** 矢印は「サーバー → Drive」の**コピー**。Drive に先に置いたファイルが自動で DocuGrid に入るわけではありません（初回整理は ZIP 取り込みなどで載せます）。

## サーバーと Drive、それぞれ何のため？

| | DocuGrid サーバー | Google Drive |
|--|-------------------|----------------|
| **役割** | 日々の業務の中心 | バックアップ・正式保管・所内閲覧 |
| **必須？** | はい（保存の本体） | いいえ（設定で ON/OFF） |
| **誰が見る？** | DocuGrid にログインしたスタッフ（権限内） | Drive の共有範囲のメンバー |
| **権限** | DocuGrid が管理 | Drive の共有設定は補助（正にはしない） |
| **容量いっぱい時** | ホストのディスク次第 | ミラーだけ失敗しうる。サーバー保存は残る |

### なぜ「サーバー ＋ Drive」にするの？

- **サーバー** … マトリクス・監査・版管理・AI 分類を速く・安全に動かすため  
- **Drive** … 事務所が慣れている保管庫、障害時のコピー、所長が Drive から一覧したいときのため  

「Drive だけで全部やる」より、「DocuGrid で整理しつつ Drive にも残す」が、税理士事務所の現場に合いやすい、という設計です。

## もともと Google Drive だけで運用していた事務所へ

よくある状況:

- 顧問先ごとにフォルダがバラバラ  
- 同名 PDF が複数箇所にある  
- Drive の容量が上限近い  

**おすすめの順番:**

1. **消さない** … 旧 Drive フォルダは移行期間の保険として残す  
2. **DocuGrid に載せる** … 顧客マスタ CSV → ZIP 一括整理（[migration.md](./migration.md)）  
3. **マトリクスで確認** … 主要顧問先・主要期を目視  
4. **Drive を整理** … 空きを作る（重複削除・アーカイブ・プラン見直し）  
5. **Drive 連携 ON** … 以降は **整理済みの PDF だけ** DocuGrid から Drive にミラー  

初回 ZIP 整理は **DocuGrid サーバーに先に載る**ので、Drive に空きがなくても取り込み自体は進められます。Drive は「移行後のきれいなコピー先」として後から整えれば大丈夫です。

詳しくは [初回データ整理](./migration.md) の「Drive 容量が逼迫しているとき」を参照。

---

## Drive の容量がいっぱいのとき

| やること | やらないこと |
|----------|--------------|
| まず DocuGrid サーバーへ整理・格納 | いきなり旧 Drive を全削除 |
| 旧フォルダを `移行前アーカイブ` などにまとめて読み取り専用 | 移行前に Drive 内で大量コピー |
| 確認後に外付け HDD 等へ退避 | Drive だけを唯一の正本にする |
| 空きができたら DocuGrid → Drive ミラーを再開 | Drive 共有リンクを権限の代わりにする |

## よくある質問（LP 向け Q&A）

**Q. ブラウザに保存される？**  
A. いいえ。ログインして格納した資料はサーバー（＋任意で Drive）です。ダウンロードしたものだけ端末に残ります。

**Q. Drive を切ったら資料は消える？**  
A. サーバーに残った資料は DocuGrid から見えます。Drive はミラーなので、OFF にしてもサーバー本体は消えません。

**Q. スタッフ全員が同じ Drive を見られる？**  
A. DocuGrid 上は事務所・権限で共有。Drive は **共有ドライブ** または **メンバー共有** の設定が必要です（[google-drive.md](./google-drive.md)）。

**Q. 顧問先に Drive のルートを渡す？**  
A. しません。顧問先への共有は DocuGrid のポータルや、必要なフォルダだけ閲覧共有、という形を推奨します。

**Q. 他の税理士事務所とデータが混ざる？**  
A. 混ざりません。事務所（firm）ごとにデータと設定が分かれています。

## LP・営業資料用コピー（そのまま転用可）

### ヒーロー見出し案

- **資料の正本は DocuGrid。Drive はそのまま活かす。**
- **マトリクスで整理し、サーバーに残し、Drive にもバックアップ。**
- **もともと Drive だけの事務所も、無理なく乗り換え。**

### サブコピー案（2〜3行）

> 税理士事務所の PDF は、まず DocuGrid のサーバーに集約。Google Drive 連携を ON にすれば、同じファイルを事務所の Drive にも自動で残します。ブラウザや個人 PC に散らばらず、マトリクス・権限・版管理はアプリ側で一元化。Drive はこれまで通りの「保管庫」として併用できます。

### 3 つの安心（箇条書き）

- **散らばらない** … 格納先はサーバー中心。スタッフはマトリクスから同じ資料を見る  
- **Drive と両立** … 連携 ON で Drive にもミラー。所内の Drive 文化を壊さない  
- **移行に配慮** … 旧 Drive は残しつつ ZIP 整理。容量逼迫時もサーバーへ先に載せられる  

### 比較表（LP 用・短文）

| 従来（Drive だけ） | DocuGrid 導入後 |
|--------------------|-----------------|
| フォルダ名がバラバラ | 顧問先 × 期 × 書類種別のマトリクス |
| 権限は Drive 共有頼み | 事務所・担当ごとにアプリで制御 |
| どれが最新版か不明 | 版管理・監査の流れに載せられる |
| 容量は Drive 次第 | サーバーに本体、Drive は整理後ミラー |

### 導入ステップ（LP 用・4 行）

1. 顧客マスタを CSV で取り込み  
2. 旧フォルダを ZIP で一括整理（AI が候補提示、人が確定）  
3. Google Drive を接続し、事務所で見えるように設定  
4. 以降の資料はマトリクスへ投入 → 自動でサーバー ＋ Drive
